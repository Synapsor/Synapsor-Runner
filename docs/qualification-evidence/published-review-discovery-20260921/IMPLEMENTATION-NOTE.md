## Implemented boundaries and retained limits

A: existing draft-list remains disabled-only. A separate typed trusted review resolver reads current governed records and bounded immutable history (100 entries). Full authority plus review material and an actual activate_action event establish draft/publication relationship; source-session/source/Read and saved semantic review bind the job. New review records also retain exact lifecycle, immutable record and selected repository/deployment/project digest. Equivalent but independently re-saved records cannot satisfy a newer exact-record binding. Another publication is an explicit current-review choice backed by the earlier immutable record, not automatic completion of that pending intent. Failed/cancelled choices preserve work; context replacement retains old contexts and does not carry the old request-completion instruction forward. Legacy active files without publication lineage, or lineage outside the bounded history, refuse rather than guess. No draft recreation, compilation, publication or runtime authority mutation is added.

The existing project authority mutex and counting-domain/store coordination remain in their existing order. Provider/user work remains outside save coordination. Preparation and save/reuse re-read exact subjects, repository identity, active Read dependencies, source decisions, prepared evidence and receipt binding. Concurrent same-semantic wrapper save also refuses stale completion. This is supported local coordination evidence, not a new multi-host guarantee.

B: exact old all-null listing carried summary only. Server text and provider-visible text were byte-identical; no detail call or truncation was observed. The unsupported inference was absence from omission/proposal_only. Shared tool/result guidance and additive disclosure indicators now mark partial summaries, current exact mode-only/manual-only, or unavailable authority. Private automatic predicates, numeric operands and limits remain absent. Current human-mode detail can state human review; paused detail cannot. Existing exact public mode is qualified by current eligibility/allowance and never execution readiness. There is no new policy declassifier or provider-specific prompt. Historic false native answer is not rewritten.
