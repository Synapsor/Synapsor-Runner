Counting: equality is a comparison of supplied scalars, not proof of source meaning. Associate an explicit limiting clause and applicable counting-set decision before either equality gate. Retain the supplied passage/citation unchanged; record the host association separately. Exact canonical outcome vocabulary comes from the current authored contract, not fixture names. The accepted mixed-passage resolver remains counting-only; numeric/condition/privacy/field/obligation checks never enter its narrow object.

Reference acquisition: references come from permitted rows roots with actual subject projection, not arbitrary related values. Check externally supplied subjects against the current reviewed Read and actual compiler. Internal relationship targets remain governed by existing Action relationship/cardinality/scope validators. Disabled incompatible work remains saveable; review/readiness and publication preparation report the missing route. Inspection never rewrites an existing activation.
