A later role or source-receipt lookup cannot retroactively fill that signed historical field. The assessor stopped **before** its source observation step. The exact item is therefore not eligible under the current authenticated closure contract. No public closure preview/confirmation, signed operator action or source transaction was attempted.

## Delayed-work contract to decide before unattended support

| Case | Current behavior established here | Proposed bounded disposition, **not implemented** |
| --- | --- | --- |
| Proof expiry only; exact operation otherwise unchanged | Terminal safe `SEMANTIC_AUTHORITY_STALE` in this run; no automatic renewal. | A new attributable, time-bounded transaction validation could re-read current authority, identity, all private/complete-collection facts, versions, effect, receipt mode and deduplication, then compare the exact approved operation. Define total age and atomicity before allowing same-request dispatch. It must not mint a second approval or copy/extend the old proof. |
| Facts, target, inputs or derived effects materially changed | Existing worker refuses a mismatched current re-verification; the expired branch did not reach this comparison. | Require a new proposal and normal approval for the changed operation. Never apply a newly derived amount under old consent. |
| Authority withdrawn or human mandate expired | Currentness checks may refuse; this run establishes only proof expiry. | Do not renew through the old approval. Require the applicable fresh authority/mandate and ordinary new decision. |
| Already applied | Existing idempotency/receipt history governs; not tested by this failure. | Return the established original effect and receipt; no second effect. |
| Commit or source outcome unknown | Not this case: a whole-transaction rollback was acknowledged. | Reconcile source/control evidence; do not retry or claim no effect from a failure code, missing receipt or current row value. |
| Terminal blocked item | This item remains blocked and is **not** closable under the current role-bound assessor. | Only the existing exact proven-no-effect administrative closure, if all its historical role/producer/source checks pass. Otherwise retain blocked history for operator resolution; no implicit retry or allowance refund. |

The design decision is whether to add an explicit delayed-work freshness-renewal contract and, separately, how to handle blocked items whose historical recovery-role binding is empty. Neither is repaired by lengthening the current five-minute TTL during this qualification. Schedule P1-EXPIRY after the current known-case lifecycle verdict and before claiming backlog-tolerant or unattended execution.
